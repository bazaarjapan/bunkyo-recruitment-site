# 文教大学付属中学校・高等学校 生徒募集サイト構想

文教大学付属中学校・高等学校の特徴を調査し、受験生・保護者に学校生活の魅力を伝えるウェブサイトを試作するための学習記録です。

## 目的

学校案内の情報を並べるのではなく、受験生が「自分なら何を発見し、どう行動し、誰と何をつくるか」を想像できる、参加型で印象に残る募集サイトを設計する。

## 現時点の仮説

- 校訓「人間愛」と、探究・協働・表現を一つの体験として見せる。
- 文教ユニバーサルコンピテンシー（発見・思考・行動・探究・表現）をサイトのナビゲーションにする。
- クリエイティブチャレンジ、GCP、ICT／生成AI、クリエイティブドックを「授業名」の紹介で終わらせず、生徒の変化のストーリーで伝える。
- 中高6学年、部活動、委員会、旗の台駅徒歩3分という日常の近さを、短い動画・スクロール演出・選択式コンテンツで見せる。

## 記録の読み方

- `docs/research-school-features.md`: 公式情報に基づく調査メモ
- `docs/issues/001-recruitment-site-concept.md`: Issue 001（最初の課題設定）
- `CHANGELOG.md`: 指示ごとの変更意図・実施内容・確認結果
- `index.html` / `styles.css`: 初期のスマートフォン対応コンセプトサイト

## 注意

「バズる」ことだけを目的にせず、学校の公式情報と実際の生徒生活から離れない表現を優先する。写真・動画・生徒の声を使う場合は、権利・個人情報・学校の公開許可を確認する。
