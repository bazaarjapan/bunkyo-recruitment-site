# 学校特徴調査メモ

調査日: 2026-08-24  
対象: 文教大学付属中学校・高等学校（東京都品川区旗の台）

## 公式情報から確認できた特徴

### 1. 教育の中心に「人間愛」と探究がある

校訓は「人間愛」。急速に変化する社会を理解し、自ら課題を探究する力、国際社会・地域社会の課題解決に対応する学力とスキルを育てる方針が示されている。

### 2. 文教ユニバーサルコンピテンシー

学校独自の力として、発見・思考・行動・探究・表現を掲げている。募集サイトでは、5つの言葉を単なる標語にせず、受験生が選択して進むインタラクティブな導線にできる。

### 3. クリエイティブチャレンジ（CC）

学年を超えた探究グループで、横断的・総合的に学び、社会貢献につながる課題を自ら立てて解決する活動。学年横断・協働・社会との接続が、学校の強い物語になり得る。

### 4. グローバルコンピテンスプログラム（GCP）

中学1年から高校1年まで、ネイティブ講師と担任によるオールイングリッシュの問題解決型学習を実施。コミュニケーション、異文化理解、リーダーシップ、チームビルディング、共感、批判的思考などを扱う。

### 5. ICT・生成AI・クリエイティブドック

タブレットPCを授業、課題配信、オンライン授業、学校行事などで活用。生成AIの活用も進めている。また、動画撮影・配信機材や3Dプリンターなどを備えた「クリエイティブドック」の活用方針が示されている。サイト自体を「つくる・試す・発信する」場として設計する根拠になる。

### 6. 中高6学年の日常と部活動

中学・高校の6学年が部活動や委員会活動で交わる場面がある。文化部・運動部あわせて約30の部活動があり、授業外の人間関係や成長も魅力として伝えられる。

### 7. 立地と規模

旗の台キャンパスは、旗の台駅・荏原町駅から徒歩3分。学校法人の計画資料では、2025年5月1日時点の生徒数は1,257人、専任教職員数は65人とされている。数値は更新され得るため、公開サイトでは出典と基準日を併記する。

## サイト企画への翻訳

| 学校の事実 | 体験としての見せ方 | 仮の企画 |
|---|---|---|
| 発見・思考・行動・探究・表現 | 5つの選択肢から自分のタイプを探す | 「あなたの文教コンピテンシー診断」 |
| 学年横断のCC | 課題が生まれ、仲間と動き、成果を表現する過程を追う | 「問いから世界を変える」 |
| GCP | 英語で協働して解決する場面を短編で見せる | 「英語は教科ではなく、世界とつながる道具」 |
| ICT・生成AI・3D／動画設備 | 生徒が制作物を公開し、見る側も選択・参加する | 「つくる学校、発信する生徒」 |
| 6学年・約30部活 | 一日の時間軸や人間関係の地図で見せる | 「6年間の毎日をのぞく」 |
