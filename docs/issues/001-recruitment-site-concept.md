# Issue 001: 文教大学付属中学校・高等学校の魅力を体験型の生徒募集サイトに翻訳する

状態: 調査・企画仮説  
作成日: 2026-08-24

## 背景

学校公式サイトには教育理念、探究、グローバル教育、ICT、学校生活などの情報がある。一方で、受験生が「自分がこの学校でどんなふうに過ごすか」を短時間で想像できる体験として再構成する余地がある。

## 目的

文教大学付属中学校・高等学校の固有性を正確に伝えながら、受験生が自分の興味から学校を探索し、説明会・募集要項・問い合わせなどの次の行動へ進めるサイトの仮説をつくる。

## 仮説

「人間愛」「探究」「グローバル」「ICT」を別々の説明項目にせず、文教ユニバーサルコンピテンシー（発見・思考・行動・探究・表現）の5段階を通して体験できる構成にすると、学校の教育方針と日常がつながって見える。

## 初期スコープ

- 学校特徴の出典付き調査
- 募集サイトのコンセプト、導線、主要セクションの設計
- スマートフォンでのファーストビューと診断／探索体験の試作
- 募集要項・説明会・問い合わせへの導線設計

## 今回は含めないもの

- 公式情報にない実績・数値・生徒の発言の創作
- 生徒の顔写真・氏名・動画の無許可掲載
- 本番ドメインへの公開、広告出稿、SNS投稿
- 入試情報の確定版としての掲載（最新要項の照合が必要）

## 完了条件（企画段階）

- 主要な学校特徴に公式出典が付いている
- 企画上の表現と事実が区別されている
- 次の実装指示ごとに「何を変えたか」「なぜ変えたか」を記録できる
- 受験生の次の行動が明確である

## 次のタスク候補

1. 受験生向けの体験フローを3案出す
2. スマートフォン用トップページのワイヤーフレームを作る
3. 公式募集要項・説明会情報を確認してCTAを確定する
4. 公開素材の権利確認チェックリストを作る

## 追加作業ログ（2026-08-24）

### 指示

参考写真、明るく活動する生徒のアニメーション風ビジュアル、TikTok・Instagram・X向けの親しみやすい画像をImageGenで作成し、サイトに公開する。

### 実施内容

- 縦型SNS用の写真風コンセプト画像とアニメーション風コンセプト画像の生成を開始。
- 実在の生徒・学校公式写真・学校ロゴを使わない条件をプロンプトに設定。
- `index.html` と `styles.css` による初期サイトを追加。
- トップページに「発見・思考・行動・探究・表現」の5つのカードとタップ時の説明表示を実装。
- 公式の入試情報・公式サイトへの導線を追加。

### 変更意図

- SNSで見られやすい縦型構図と、タップして自分の入口を選ぶ体験を組み合わせる。
- 学校の特徴を一般的な学校紹介ではなく、受験生が自分ごと化できるインタラクションとして提示する。
- AI生成画像は、実在の生徒の記録や公式広報素材ではなく、あくまで企画検証用の参考ビジュアルとして扱う。

### 公開時の確認事項

- AI生成であることを必要に応じて表示する。
- 学校の正式な承認なしに、公式アカウント・公式募集広告として投稿しない。
- 最新の募集要項、説明会情報、写真・動画の利用許諾を確認してから本番素材へ差し替える。
